# Historical OpenRouter decision trial

The compatible OpenRouter adapter supplies fresh per-member judgments to the existing environment. The trial records request metadata, returned probabilities, sampled actions and state transitions. Source configurations, numerical results and receipts are preserved in the tables and linked records below. New model runs use an environment credential and an explicit paid allowance; free replay uses saved probabilities.

The featured convention and majority results supersede this connection pilot for the proposal's behavioral examples. Native batch support is provided by the typed Jev adapter; independent chat completions are recorded as such.
