# Nature-family candidate screening

Candidate selection prioritizes original studies with LLM-driven individual choices, repeated interaction and endogenous feedback. A one-shot survey, static prediction task or conventional rule model with a new Jev adapter answers a different compatibility question. Original data, code and protocol availability determine whether a source condition can be reproduced.

The screening records below retain the papers and resources consulted. The current featured Nature-family examples are Akata et al. in Nature Human Behaviour and Piao et al. in Nature Communications. Source-specific methods and completed horizons appear in their dedicated records.
