# Organizational social learning

This recipe compares siloed and bridge contact structures for 120 members in four departments, over 20 rounds and three seeds: six worlds. Members keep a solution, explore, or copy an observed solution. The environment evaluates the NK landscape and applies the positive-improvement adoption rule.

An independent Python implementation checks the Mesa adapter's observations, choices, solutions and metrics. This comparison targets the declared Python reference, rather than reproducing the random stream of a separate R implementation.

## Configuration and execution

```bash
python -m examples.abm_cookbook.run --model organization --output runs/organization-through-ordo
```
