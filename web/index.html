People and organization

Import or define Personas, then configure departments, positions, and reporting relationships. A separate population seed fixes membership across institutional comparisons.

Import public or custom records

Browser import accepts up to 1 MB. Select larger subsets with Python. Records retain source and license metadata.

Define roles and assignments. Actions are keep, explore, and copy. Custom assignments specify agent, department, role, and manager; IDs start at zero and departments contain at least four members.

In this learning scene, managers also choose work methods. Rules enforce role rights and departmental contact constraints.

Personas are not enabled.

Construct a position-conditioned population

Jev scores how likely a Persona is to occupy a position. Pool mode scores all candidates and samples by probability weights; streaming mode accepts sampled candidates at the threshold. Each Persona fills at most one position.

Default acceptance is at least 50%. Unfilled positions remain visible at the chosen threshold.

Preview locally, then execute through start_persona_assignment in Harness or the command below. Assignment and simulation costs are recorded separately.

python -m orgabm assign-personas --job persona-assignment-job.json --preview

METHOD & EVIDENCE
Trace organizational interventions through execution

      
01
An existing ABM provides the environment
The NK environment supplies work methods, social learning, local search, and synchronous updates. Members observe outcomes of tried methods.
Author source code ↗
02
Organizational modules define conditions
Departments restrict information, identity settings shape records, approval thresholds govern adoption, and penalties enter realized payoffs.
This scene implements the approval threshold as an institutional rule.
03
Decision engines choose actions
Each relevant event receives a new judgment. Native batches combine ready decisions before the world updates.
The simulator samples actions from validated engine probabilities.
